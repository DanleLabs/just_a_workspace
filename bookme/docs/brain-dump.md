# Brain dump (сырая выгрузка) — bookme

> Всё, что сказал основатель, без сортировки. Сортировка в `product-map.md`.

## Ядро
- Букинг для ресторанов и кофешек — основная идея.
- Заметка-триггер: в СНГ «рвёт» Яндекс (экосистема, UX), в Европе аналога с таким UI/UX тупо нет.

## Сценарий гостя (как видел основатель)
- Сидя в машине: листаешь меню на родном языке.
- Смотришь аллергены, состав.
- Получаешь маршрут в Google Maps, чтобы найти заведение.
- Бронируешь место.
- Видишь ограничение по времени, установленное этим конкретным заведением (тайм-слот).

## Сценарий заведения
- Трекинг зала (кто/сколько за каким столом).
- Статистика: сколько посетителей, что нравится, что заказывают, сезонность, когда зал наполняется.
- Подсветка пустых столов и заполнение по мере посещаемости → рост среднего чека / оборачиваемости.
- Тайм-лимиты на столы как настройка заведения.

## Мета
- Юзеры получают агрегатор + одно приложение для всех заведений.
- Электронное меню / заказ из-за стола (из исходной подкинутой идеи: ТГ-бот + миниапп).
- Сцена-кофе: гость сидит 47 мин с одним кофе → система подсвечивает → мягкий оффер вместо выговора.
- База гостей (Stammgäste), напоминания о брони (no-show).
- Доставка (упоминалась в ранней версии идеи).
- Гео: Германия, городок рядом с Регенсбургом. Основатель говорит по-немецки.
